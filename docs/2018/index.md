## About

The second international conference «Bioinformatics: from Algorithms to Applications»
was held on July 16–19, 2018 in Saint Petersburg, Russia. The program included a half-day
workshop on QIIME for microbiome analysis given by Amanda Birmingham and Rob Knight (UC San Diego).

**Topics:** Sequencing technologies · Molecular sequence analysis · Computational genomics ·
Genome assembly · Transcriptomics · Metagenomics · Immunogenomics · Viromics · CRISPR
